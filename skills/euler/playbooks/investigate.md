# Investigation

Keep files unchanged unless the user asks for edits or an experiment requires a disposable artifact.

1. Turn the question into the facts needed to answer it.
2. Use the strongest available source: running code, project files, git history, official docs, or a minimal experiment.
3. Separate observed facts from inference.
4. Stop when the answer is decision-ready.

Report the answer first, then the evidence and any remaining uncertainty. Cite files, commands, or sources where useful.
