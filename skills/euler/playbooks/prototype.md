# Prototype

1. Name the single question the prototype answers.
2. Build the smallest runnable or visual slice that can answer it. Prefer existing code and placeholders over production infrastructure.
3. Mark the shortcuts that would not belong in the final product.
4. Run it and inspect the result. Capture a screenshot when the question is visual.
5. Stop when the question has an answer.

Report the answer, the artifact, how to run it, and the decision it enables. Do not promote prototype code into product code without saying so.
