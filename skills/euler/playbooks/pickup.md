# Session pickup

1. Reconstruct the current state from the conversation, git status and recent commits, specs, plans, and relevant notes. Use `recall` when earlier sessions may hold decisions or implementation history.
2. Identify what has been decided, what is implemented, what is uncommitted, and what remains.
3. Confirm uncertain state from files or commands rather than memory.
4. Continue the next unfinished step when intent is clear.

When reporting before continuing, keep it to current state, next step, and any decision that blocks progress.
