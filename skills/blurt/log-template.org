* How a round works
Run =/blurt= (it picks the topic) or =/blurt <topic>= from this course directory or below.
1. *Cue:* Pi gives a topic title only. Close everything.
2. *Blurt:* write or dictate everything you remember into the chat or the round file.
3. *Check:* Pi grades against the sources (✓ ~ ✗ ∅) and points to them for the gaps.
4. *Fill:* read only the pointed-to sections, then say =ready=.
5. *Gap round:* 3–5 recall questions on the gaps only.
6. *Log:* score, open gaps and next review date land below.
